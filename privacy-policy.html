Prism

Privacy Policy

Last updated: September 24, 2026

Prism does not collect, store, transmit, or share any personal data. All processing happens entirely within your browser.

1. Overview

Prism is a browser extension that formats and displays raw JSON responses as a readable, collapsible tree view. It operates entirely locally — no data is ever sent to any external server.

2. Data We Do Not Collect

Prism does not collect or transmit any of the following:

  • Personal information (name, email, IP address, etc.)
  • Browsing history or URLs you visit
  • The content of JSON responses you view
  • JSON schemas you enter into the validator
  • Usage statistics or analytics
  • Crash reports or diagnostic data

3. Local Storage

Prism uses chrome.storage solely to save your preferences on your own device:

  • Theme preference — whether you last used dark or light mode

This data never leaves your device and is not accessible to anyone other than you.

4. Permissions Explained

The permissions requested by Prism are the minimum required for it to function:

  • storage — saves your theme preference locally
  • scripting — injects the formatter UI into JSON pages
  • webRequest — detects JSON content-type responses
  • declarativeNetRequest — rewrites JSON content-type headers so the browser renders the raw text instead of its built-in viewer
  • host permissions (<all_urls>) — required because JSON APIs exist on any domain; the extension only activates on pages that return JSON

None of these permissions are used to access, read, or transmit your data.

5. Third-Party Services

Prism does not integrate with any third-party services, analytics platforms, or advertising networks. No external scripts are loaded at runtime — all code is bundled locally within the extension.

6. Remote Code

Prism does not execute any remotely hosted code. All JavaScript runs from within the extension package itself, fully compliant with Chrome's Manifest V3 security requirements.

7. Children's Privacy

Prism does not knowingly collect any information from anyone, including children under the age of 13.

8. Changes to This Policy

If this privacy policy is updated, the new version will be published at the same URL with a revised "Last updated" date. Continued use of the extension after any changes constitutes acceptance of the updated policy.

9. Contact

If you have any questions about this privacy policy, you can open an issue on the project repository or contact the developer directly through the Chrome Web Store listing.
